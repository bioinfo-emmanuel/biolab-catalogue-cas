# BS Biology Lab Catalogue

Low-resource lab activities for BS Biology subjects, with R scripts and Excel workbooks for the analysis.
Compiled by Emmanuel G. Lozano, Department of Biology, College of Arts and Sciences, Pampanga State University.

- `index.html` is the whole app (the data is inside it).
- `R_scripts/` holds the R scripts shown on the cards.
- `workbooks/` holds the Excel workbooks linked from the cards.
- `assets/` holds the logo files, favicon and share image (see `assets/README.txt`).

Original material is licensed CC BY-NC 4.0 (see `LICENSE.md`). No activity has been run with students unless its card says so.

To update: replace `index.html`, and add or replace files in `workbooks/` or `R_scripts/`. The catalogue version is shown in the page footer.
