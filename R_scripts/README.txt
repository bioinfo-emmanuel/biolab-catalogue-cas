BS Biology Lab Catalogue: R scripts for the promoted cards (74 scripts)
Tested on R 4.3.3, base R only (no packages). Run with:  Rscript scriptname.R
With no arguments every script runs on built-in or simulated practice data and prints its results.
Some scripts also save a PNG in the working folder. All practice data are invented or built into R; none are real measurements.
Optional input files for each script are described in the comment lines at the top of the script.
